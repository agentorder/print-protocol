# Stewardship and contributions

AgentOrder Print Protocol is an early founder-led project maintained in the `agentorder` GitHub organisation. It is not currently governed by an independent foundation, industry consortium or elected committee.

The protocol and reference implementation can be implemented and hosted without an AgentOrder.tech account. A hosted product must not be the only way to use a published protocol feature. Commercial-provider-specific features should be clearly identified as extensions.

## Contributing

Open an issue with a print-ordering use case, a proposed message, or a concrete interoperability problem. Propose changes through pull requests containing updated specification text, schemas, examples and relevant tests. Do not submit real customer details, artwork, credentials or payment information.

Maintainers review changes for print relevance, explicit customer control, implementability by independent printers, and migration impact. Before merging a breaking change, identify affected clients and assign a new protocol version. Draft 0.x versions may change; published examples must state their version.

Run `python -m unittest -v` before a code/schema pull request. Contributions are under the repository's MIT License. No contributor agreement or foundation membership is required by this draft process.

## Decisions still open

Before 1.0, publish a maintainer roster, decision and appeal process, extension policy, release policy and a plan for independent printer participation. Any future governance body must be described accurately when established; the `.org` domain alone does not establish independence.
